Mixture-of-Experts (MoE) models route each input to a sparse subset of experts, realizing capability through per-input expert specialization. We ask whether the same per-input principle that gives MoE its capability efficiency can be repurposed for alignment, observing that on a given input, some experts amplify unsafe behavior while others suppress it, and the split depends on the query. Realizing this requires a router that selects experts based on a second axis beyond capability, namely the safety relevance of each expert for the current input. This raises two coupled challenges. First, the identity of risk-amplifying experts shifts from query to query, since different risk domains expose disjoint harmful surfaces of the model and engage largely disjoint expert subsets, so the safety-relevant set must be identified per input rather than globally. Second, queries themselves vary in risk level, with clearly malicious prompts demanding strong correction while benign ones warrant none, so the intervention strength must be calibrated per input. We propose \name{}, an alignment-enhancing technique inspired by MoE's per-input routing principle, addressing both challenges with a single forward-backward pass per input. Gradients of a harmfulness signal with respect to router logits localize each query's risk-amplifying experts, and the magnitude of the same signal sets the strength of the router-level bias applied to suppress them. Across three MoE LLMs (OLMoE-1B-7B, Qwen1.5-MoE-A2.7B, Mixtral-8x7B) and a diverse set of risky inputs, this raises average safety by over $20\%$ relative to the unintervened MoE while preserving benign helpfulness within $0$\,pp of the original model, validating that MoE's per-input routing principle extends from capability to alignment.
